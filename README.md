# HongXingWeb

Hong Xing 技术 / 项目 / 服务官网。

## 当前实现

- 黑、白、原始红 `#FE2601` 三色 UI；Amia_晓山瑞希项目形象保持彩色显示。
- 导航、favicon 与首页主视觉使用依据原始标志重建的 Hong Xing SVG；高 DPI / 4K 下保持矢量清晰度。
- 首页主标志由多层 SVG 构建立体厚度，支持透视、指针倾斜、滚动缩放与视差，不使用平面 3D 效果图冒充实时模型。
- 首页采用 NANFU 式长滚动叙事：品牌首屏 → 三项核心原则 → 项目横向舞台 → O3 / Quick Services 技术舞台 → 近期动态 → 苏州 → 南京迁移 → Amia 关联 → 发展时间线。
- 桌面端「三项原则 / 项目 / 历史」使用 pinned scroll scene：纵向滚动推进章节，内容在固定舞台内切换或横向移动。
- 手机端不使用纵向手势驱动横向滑块；项目、动态、历史统一改为浏览器原生横向滚动 + Scroll Snap，避免上下滑动误触发左右切换。
- O3 区使用独立 390vh 技术滚动场景，Quick Start / Quick Connect / Quick Route 随滚动阶段切换。
- 苏州 / 南京迁移区使用 CSS / DOM 建筑建模；独立基础设施页提供双城模型、迁移路线、建筑升起与滚动迁移效果。
- 项目页增加独立章节轨、全屏项目段落与 O3 深色技术场景。
- 更新公告支持搜索、分类筛选、分页、URL 查询状态、详情弹窗与 hash 深链接。
- 生命周期页增加滚动时间线进度；生态页保持 Amia 彩色主视觉并加入轻量视差。
- 子页面统一使用大标题、黑白红视觉、全屏菜单、直角信息区块、页面过渡与滚动进入动画。
- 完整页面：项目与服务、基础设施、更新公告、生态关联、生命周期、支持与下载、关于、404。
- 支持 `prefers-reduced-motion`，降低动画需求时取消 pinned / parallax 等强运动效果。

## 内容原则

- HongXingOS、O3、AuthLit、HX Online2 分别展示，不以单一项目代表全部 Hong Xing。
- 不虚构用户量、SLA、全球节点、迁移百分比、下载地址或设备兼容清单。
- 公开文案优先依据时间更晚的正式公告；历史状态冲突时保留时间线并说明后续变化。
- 项目图片只使用已确认素材。
- 参考 NANFU 的页面节奏、信息层级与交互方式，不复制其商标、产品图片、专有文案或其他品牌资产。

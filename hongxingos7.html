开发预览环境

当前预览版本优先验证系统框架、桌面环境、窗口管理、图形栈与 Hong Xing 服务体系之间的基础协同，不代表最终稳定版本的界面与功能范围。

Base

Arch Linux

以 Arch Linux 为当前开发基础，便于控制组件版本、系统结构与开发阶段的快速迭代。

Desktop

Plasma + KWin

当前开发预览采用 Plasma 桌面与 KWin 窗口管理器，重点验证桌面交互、窗口行为与系统设置整合。

Graphics

Wayland

当前预览使用 Wayland 图形平台，并继续测试应用兼容、显示链路及桌面环境行为。

Architecture

x86_64

当前公开预览以 x86_64 作为主要开发与测试架构。

Firmware

O3 Integration

O3 计划作为 HongXingOS 7 默认固件体系的一部分，承担启动、服务调度、最小预加载及兼容性维护。

Lifecycle

Preview Stage

当前仍属于开发预览阶段；发布范围、最终功能与稳定版时间以后续正式公告为准。

System Stack
